# 📝 Round 1 – Concept Questions (15 Marks)

## Q1. Who developed Java and what was its original name?

**Answer:**
- Developed by **James Gosling** and his team at **Sun Microsystems**.
- Originally named **Oak**.
- Later renamed **Java**.

---

## Q2. What is WORA?

**Answer:**

**WORA = Write Once, Run Anywhere**

Java programs are compiled into **bytecode**, which can run on any operating system that has a **JVM**.

---

## Q3. Differentiate between JDK, JRE and JVM.

| JDK | JRE | JVM |
|-----|-----|-----|
| Java Development Kit | Java Runtime Environment | Java Virtual Machine |
| Used for development | Used to run Java programs | Executes bytecode |
| Contains JRE | Contains JVM | Converts bytecode into machine code |

### Relationship

```
JDK
 └── JRE
      └── JVM
```

---

## Q4. Why is Java platform independent?

**Answer:**

Java is platform independent because source code is compiled into **bytecode**, which can run on any operating system having a JVM.

---

## Q5. What is Bytecode?

**Answer:**

Bytecode is the intermediate code generated by the **Java compiler (javac)**.

It is stored in the **.class** file and executed by the JVM.

---

## Q6. Why is `main()` declared as `public static void`?

| Keyword | Purpose |
|----------|---------|
| public | JVM can access the method |
| static | JVM can call it without creating an object |
| void | Returns no value |

---

## Q7. What is a Variable?

**Answer:**

A variable is a named memory location used to store data whose value can change during program execution.

---

## Q8. What is a Data Type?

**Answer:**

A data type specifies:
- The kind of data that can be stored.
- Memory required.
- Operations allowed.

---

## Q9. What is a Literal?

**Answer:**

A literal is a fixed value written directly in a Java program.

Examples:

```java
20
'A'
"Java"
true
```

---

## Q10. Difference between Keyword and Identifier

| Keyword | Identifier |
|----------|------------|
| Reserved word | User-defined name |
| Predefined meaning | Used to name variables, classes, methods |
| Cannot be used as identifiers | Must follow naming rules |

---

## Q11. Can String be considered a keyword?

**Answer:**

No.

`String` is a predefined class, not a keyword.

---

## Q12. What are Comments?

**Answer:**

Comments are non-executable text written to explain code.

They are ignored by the compiler and JVM.

---

## Q13. How many primitive data types are there?

**Answer:**

There are **8 primitive data types**.

- byte
- short
- int
- long
- float
- double
- char
- boolean

---

## Q14. Why is double preferred for CGPA?

**Answer:**

Because CGPA contains decimal values, and `double` stores decimal numbers with higher precision.

---

## Q15. Difference between `char` and `String`

| char | String |
|------|--------|
| Stores one character | Stores multiple characters |
| Uses single quotes (' ') | Uses double quotes (" ") |
| Primitive type | Reference type (Class) |

# 📝 Round 5 – Error Identification (15 Marks)

| Code | Status | Reason |
|------|--------|--------|
| `int class=20;` | ❌ Error | `class` is a keyword |
| `int 2age=30;` | ❌ Error | Identifier cannot start with a digit |

# 📝 Round 6 – Interview Questions (15 Marks)

## Q1. Why is String a class and not a primitive?

**Answer:**

String is a class because it provides built-in methods like:

- length()
- substring()
- equals()
- charAt()

Primitive data types cannot have methods.

---

## Q2. Explain Java program execution.

```
Source Code (.java)
        │
        ▼
Java Compiler (javac)
        │
        ▼
Bytecode (.class)
        │
        ▼
JVM
        │
        ▼
Machine Code
        │
        ▼
Output
```

---

## Q3. Difference between char and String

```java
char ch='A';
```

Stores a single character.

```java
String s="A";
```

Stores a String object containing one character.

---

## Q4. Can an identifier start with `_` or `$`?

**Answer:**

Yes.

Examples:

```java
_count
$salary
```

Although valid, they are generally not recommended in regular Java code.

---

## Q5. Why write comments if the compiler ignores them?

**Answer:**

Comments improve readability, maintenance, collaboration, and documentation for developers.
