# Coding Exercises

> **Module 16 – Command Line Arguments**

---

# Instructions

- Write each program using **Command Line Arguments**.
- Validate the number of arguments before processing.
- Handle invalid numeric input where appropriate.
- Use meaningful variable names and proper formatting.

# Beginner Level

## Exercise 1 – Print Your Name

Pass your name as a command line argument and print it.

### Example

Input

```bash
java Name Jyothi
```

Output

```
Jyothi
```

# Expected Learning Outcomes

After completing these exercises, you should be able to:

- Read command line arguments confidently.
- Convert Strings into numeric data types.
- Validate input.
- Build small command-line applications.
- Apply Java fundamentals in practical problems.
