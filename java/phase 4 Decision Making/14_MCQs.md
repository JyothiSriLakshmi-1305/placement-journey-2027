# Beginner MCQs (1–25)

---

## MCQ 1

Which statement is used to execute a block of code only when a condition is true?

A. switch

B. if

C. for

D. break

**Answer:** B

**Explanation:**

The `if` statement executes its block only when the specified condition evaluates to `true`.

**Difficulty:** 🟢 Beginner

---

## MCQ 2

Which data type must an `if` condition evaluate to?

A. int

B. float

C. boolean

D. String

**Answer:** C

**Explanation:**

In Java, the condition inside an `if` statement must evaluate to a `boolean` value (`true` or `false`).

**Difficulty:** 🟢 Beginner

---

## MCQ 4

How many `else` blocks can be associated with a single `if` statement?

A. Unlimited

B. One

D. Three

**Explanation:**

An `if` statement can have at most one `else` block.

## MCQ 9

What happens if `break` is omitted in a traditional `switch`?

A. Compilation error

B. Runtime exception

C. Fall-through occurs

D. Program terminates

**Answer:** C

**Explanation:**

Execution continues into the next case until a `break` or the end of the switch is reached.
