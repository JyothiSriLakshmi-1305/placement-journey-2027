## Basics of Java

# Day 1 - Java Basics ☕

## Topics Covered

### 1. Introduction to Java

Java is a high-level, object-oriented programming language developed by Sun Microsystems. It is widely used for developing web, desktop, mobile, and enterprise applications.

### 2. Features of Java

* Platform Independent
* Object-Oriented
* Secure
* Robust
* Multithreaded
* Portable
* High Performance

### 3. JVM, JRE, and JDK

* **JVM (Java Virtual Machine):** Executes Java bytecode.
* **JRE (Java Runtime Environment):** Provides libraries and JVM to run Java applications.
* **JDK (Java Development Kit):** Contains JRE and development tools like compiler and debugger.

### 4. Structure of a Java Program

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
```

* Class Declaration
* Main Method
* Statements inside the main method

### 5. Input and Output Statements

**Output**

```java
System.out.println("Hello World");
```

**Input**

```java
import java.util.Scanner;

Scanner sc = new Scanner(System.in);
int num = sc.nextInt();
```

## Key Takeaway

Today I learned the fundamentals of Java, including its features, architecture (JVM, JRE, JDK), program structure, and basic input/output operations.
