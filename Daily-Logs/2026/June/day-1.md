##  Luhn's Algorithm

📌 Learned about Luhn's Algorithm, a checksum algorithm used to validate numbers like credit cards and IMEI numbers.

### How it works
- Double every second digit from the right.
- If the result is greater than 9, subtract 9.
- Add all digits.
- If the sum is divisible by 10, the number is valid.

### Applications
- Credit Card Validation
- Debit Card Validation
- IMEI Verification
- Membership IDs

### Key Takeaway
A simple algorithm used to detect data-entry errors in identification numbers.
