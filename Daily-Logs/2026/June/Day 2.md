# Day X - Video Thumbnail Optimization (Sprite Sheets & VTT)

## 📌 Overview
Learned how video platforms display preview thumbnails when users hover over the video progress bar.

## 📚 Key Concepts
### 1. Sprite Sheet
- Combines multiple thumbnails into a single image.
- Reduces the number of image requests.

### 2. VTT (WebVTT) File
- Stores timestamp information.
- Maps video timestamps to thumbnail positions in the sprite sheet.

### 3. Performance Optimization
- Uses one image instead of thousands of separate thumbnails.
- Improves loading speed and user experience.

## ✅ Benefits
- Faster loading
- Reduced network requests
- Better user experience
- Optimized video streaming

## 💡 Key Takeaway
Video preview thumbnails are generated using sprite sheets and VTT metadata, enabling efficient thumbnail loading while minimizing bandwidth and resource usage.
