# Day 1 - Introduction to SQL

## What is SQL?
SQL (Structured Query Language) is a standard language used to communicate with relational databases.

## Why SQL?
- Store data
- Retrieve data
- Update data
- Delete data

## CRUD Operations
- CREATE
- READ
- UPDATE
- DELETE

## Applications
- Banking
- E-commerce
- Healthcare
- Education

## Key Takeaways
- SQL is a query language.
- SQL works with relational databases.
- SQL is widely used in software development.
