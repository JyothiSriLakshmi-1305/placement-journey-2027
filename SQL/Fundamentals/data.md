# 📖 What is Data?

## Interview Definition

**Data is a collection of raw facts, figures, or values that can be processed to produce meaningful information.**

> **Interview Tip:** This is the standard definition expected in interviews.

---

# 🤔 Why Do We Need Data?

Every software application works with data.

Without data, applications cannot perform any useful operations.

### Examples

| Application               | Data Stored                     |
| ------------------------- | ------------------------------- |
| WhatsApp                  | Messages, Contacts              |
| Instagram                 | Posts, Likes, Followers         |
| Amazon                    | Products, Orders                |
| Banking System            | Customer Accounts, Transactions |
| College Management System | Student Records                 |

---

# 🌍 Real-Life Example

Imagine a college student record.

| Roll No | Name   | Branch | CGPA |
| ------- | ------ | ------ | ---- |
| 101     | Jyothi | AIML   | 8.78 |

Each value (Roll Number, Name, Branch, CGPA) is **data**.

The collection of all student records is also considered **data**.

# 🔄 Data vs Information

| Data                | Information                   |
| ------------------- | ----------------------------- |
| Raw facts           | Processed and meaningful data |
| Not directly useful | Helps in decision-making      |
| Input               | Output after processing       |

### Example

### Data

```
95
88
91
```

### Information

```
The average marks of the class is 91.3.
```

# 💡 Data Flow

```

   Processing
        ↓
Meaningful Information
```

# 🎤 Interview Questions

## Q1. What is Data?

**Answer:**

Data is a collection of raw facts, figures, or values that can be processed to produce meaningful information.

---

## Q2. Give some examples of data.

**Answer:**

* Student marks
* Employee salary
* Customer phone number
* Product price
* Bank account balance

---

## Q3. Is "Jyothi" data?

**Answer:**

Yes. It is textual data.

---

## Q4. Is "98" data?

**Answer:**

Yes. It is numeric data.

---

## Q5. What is the difference between Data and Information?

**Answer:**

Data consists of raw facts, while information is processed data that has meaning and is useful for decision-making.

---

# ⚠️ Common Interview Trap

### Question

**What is Information?**

### Incorrect Answer

> Information is data.

### Correct Answer

> Information is processed and meaningful data obtained from raw data.

# 📚 Key Takeaways

* Data is a collection of raw facts and figures.
* Information is processed and meaningful data.
* Every software application stores and processes data.
* Data can be numeric, textual, decimal, date, or boolean.
* Good data should be accurate, complete, consistent, reliable, and secure.
